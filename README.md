# Deep Thought

Ask Deep Thought, the supercomputer from Douglas Adams' *The Hitchhiker's Guide to the Galaxy*, any question you like. It ponders for a moment, muses to itself, and then explains, with great confidence, why the answer is Forty-Two.

**Live site:** https://ncerny.github.io/deepthought

> **For entertainment purposes only.** Deep Thought's answers are generated by an AI model and are meant to be silly. Don't take them as advice of any kind.

## Why this exists

This is a portfolio project. I built it to learn [Svelte](https://svelte.dev) and try something new, and to see how a simple AI chatbot fits into a small website. It's small on purpose: one page, one question, one answer.

## How it works

1. You type a question.
2. Deep Thought "thinks": the page shows rotating philosophical musings while it waits.
3. The site sends your question to a small Cloudflare Worker, which asks an AI model (through [OpenRouter](https://openrouter.ai)) to answer in Deep Thought's voice.
4. The answer streams back and appears one character at a time.

If the AI service is unavailable, the site falls back to one of its built-in Forty-Two answers, so you always get a reply.

## Tech stack

| Part | Technology |
| ---- | ---------- |
| Frontend | [SvelteKit](https://svelte.dev/docs/kit) (Svelte 5) with TypeScript, built as a static site with `@sveltejs/adapter-static` |
| Styling | Plain CSS with custom properties, no framework |
| Audio | Web Audio API for the optional ambient hum |
| AI backend | [Cloudflare Worker](https://developers.cloudflare.com/workers/) that calls OpenRouter and streams the reply back over server-sent events |
| AI models | Free models on OpenRouter, tried in order with automatic fallback (set in `cloudflare-worker/wrangler.toml`) |
| Hosting | GitHub Pages, deployed by GitHub Actions on every push to `main` |

See [docs/tech-stack.md](docs/tech-stack.md) and [docs/architecture.md](docs/architecture.md) for more detail.

## Project layout

```
src/                  SvelteKit app (the website)
  lib/components/     Question input, thinking display, answer display, audio
  lib/data/           Built-in musings and fallback answers
  lib/stores/         App state (idle → thinking → answer)
  lib/config.ts       URL of the AI worker
cloudflare-worker/    The API that talks to the AI model
docs/                 Design and architecture notes
```

## Running it locally

You need Node.js 20 or later.

### The website

```sh
npm install
npm run dev
```

Then open the URL Vite prints (usually http://localhost:5173). In development the site calls the worker at `http://localhost:8787`. Without the worker running, you'll still get the built-in fallback answers.

### The AI worker (optional)

You need an [OpenRouter API key](https://openrouter.ai/keys).

```sh
cd cloudflare-worker
npm install
echo 'OPENROUTER_API_KEY=your-key-here' > .dev.vars
npm run dev
```

`.dev.vars` holds your local secret. Don't commit it.

## Building and deploying

```sh
npm run build     # static site in build/
npm run preview   # preview the production build
npm run check     # type-check
```

- **Website:** pushing to `main` builds the site and deploys it to GitHub Pages (`.github/workflows/deploy.yml`).
- **Worker:** deploy with Wrangler and set the API key as a secret:

  ```sh
  cd cloudflare-worker
  npx wrangler secret put OPENROUTER_API_KEY
  npm run deploy
  ```

  If the worker's URL changes, update `PROD_API_URL` in `src/lib/config.ts`.
